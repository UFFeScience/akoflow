Environments endpoint

Update Environment Connection

PUT/environment-connections/{connectionId}/

Path parameters

connectionId
Identifier used by the registered route.

Request body

application/json

See the request guidance below for a valid body.

cURL template
curl --fail-with-body \
  -H "Authorization: Bearer ${AKOFLOW_API_TOKEN}" \
  -H "Content-Type: application/json" \
  --data-binary @request.json \
  -X PUT \
  "${AKOFLOW_API_URL}/environment-connections/{connectionId}/"

Supply a valid request.json before running this command.

Replace the path identifiers with IDs from your instance.

200 OKapplication/json

Field shape inferred from Go types; inspect the returned JSON for actual values and optional fields.

{
  "id": "string",
  "environmentId": "string",
  "name": "string",
  "type": "string",
  "endpoint": "string",
  "username": "string",
  "credentialRef": "string",
  "configuration": {},
  "createdAt": "2026-01-01T00:00:00Z"
}

Handler-checked behavior​

Read the current connection in GET /environments/{environmentId}/, then send its complete object with the changed fields. Its id must match the path and environmentId must be non-empty. The route inserts a new connection or replaces saved fields, and returns the submitted object without running a health check. See the HPC connection guide.

See the Environments guide for related tasks and context.

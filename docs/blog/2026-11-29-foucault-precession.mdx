The same pendulum workflow took **273.21 seconds with one slot** and **82.08 seconds with five** on the reference host. AkôFlow recorded the timing of each activity, so you can see which calculations ran together and where the workflow waited for results.

<!-- truncate -->

## Five latitudes, one comparison

The workflow integrates one sidereal day at latitudes −60°, −30°, 0°, +30°, and +60°. Each branch works from its own initial conditions and can run as soon as its inputs and a slot are available. Downstream activities compare the trajectories with the exact small-angle solution, check step refinement, and render the combined result.

The results recover the expected change in precession direction across the equator. The maximum coordinate disagreement with the exact solution was **2.18 × 10⁻⁸ m**.

## What the timeline shows

All five latitude activities overlapped for **56.25 seconds** in the five-slot run. Compare the full execution times to see the effect of those overlapping intervals. The observed **3.33×** makespan ratio applies to these two runs on this host with the same workflow image.

The curves show metrics from an OceanBench tutorial for two GLONET forecast initializations in January 2024. AkôFlow ran nine independent metric calls against a checksum-verified input snapshot, then combined their outputs and checked the resulting tables against the pinned tutorial notebook.

The reference run completed **13 activities** and passed validation after resuming from a local container startup timeout.

## Follow the metric branches

Preparation pins the public input objects and their checksums. The metric activities evaluate forecasts against the reference data, then aggregation and plotting turn the tables into the graphics below. The final validation checks table cells and coverage fields at the displayed precision of the original notebook.

## Reproduce the tutorial workflow

Import version 3 in Desktop using the URI below. The [source bundle](https://github.com/UFFeScience/akoflow-examples/tree/main/oceanography/oceanbench-glonet) documents the public inputs, scientific implementation, preflight, and execution records.

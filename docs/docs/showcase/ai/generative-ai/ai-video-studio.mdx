# AI Video Studio

This runnable example turns a versioned creative brief into a complete short video without a hosted model or API. Python creates the storyboard, deterministic illustrations, and narration waveform; FFmpeg produces the MP4 inside the provided image.

## Run locally

```bash
git clone https://github.com/UFFeScience/akoflow-examples.git
cd akoflow-examples/generative-ai/video-studio
./run.sh
```

The default smoke profile is CPU-compatible. Set `AKOFLOW_PROFILE=demo` for a longer render. FFmpeg is optional for the host fixture; the OCI image includes it and creates an H.264/AAC MP4.

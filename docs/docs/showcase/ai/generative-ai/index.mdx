# Generative AI workflows

RAG, synthetic data, speech, and document-processing patterns. Each workflow below has its own page with a DAG, inputs, outputs, provenance, and execution considerations.

| Workflow | Purpose |
| --- | --- |
| [RAG index construction and evaluation](/docs/showcase/ai/generative-ai/rag-indexing) | Build a retrievable knowledge index and validate it before publication. |
| [Synthetic dataset generation](/docs/showcase/ai/generative-ai/synthetic-dataset) | Generate, filter, deduplicate, review, and publish synthetic records. |
| [Audio transcription and summarization](/docs/showcase/ai/generative-ai/audio-transcription) | Transcribe segments concurrently, restore chronology, and produce a traceable summary. |
| [OCR and document extraction](/docs/showcase/ai/generative-ai/document-extraction) | Combine native extraction and OCR before validating structured records. |
| [AI Video Studio](/docs/showcase/ai/generative-ai/ai-video-studio) | Produce an offline storyboard, parallel visual and audio assets, and a validated video. |
| [Local RAG Factory](/docs/showcase/ai/generative-ai/local-rag-factory) | Build, query, cite, and evaluate a deterministic local retrieval index. |

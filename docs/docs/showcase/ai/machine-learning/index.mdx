# Machine Learning workflows

Training, evaluation, optimization, inference, and model lifecycle patterns. Each workflow below has its own page with a DAG, inputs, outputs, provenance, and execution considerations.

| Workflow | Purpose |
| --- | --- |
| [Training with MLflow](/docs/showcase/ai/machine-learning/training-with-mlflow) | Train and register a model while preserving data, parameters, metrics, and artifacts. |
| [Hyperparameter search](/docs/showcase/ai/machine-learning/hyperparameter-search) | Explore independent configurations in parallel and select one with a reproducible objective. |
| [LoRA fine-tuning](/docs/showcase/ai/machine-learning/lora-fine-tuning) | Produce lightweight adapters from a pinned base model and instruction dataset. |
| [Batch inference](/docs/showcase/ai/machine-learning/batch-inference) | Partition a large input, infer concurrently, and merge traceable predictions. |
| [Comparative model evaluation](/docs/showcase/ai/machine-learning/model-comparison) | Evaluate candidate models with the same immutable dataset and policy. |
| [Model conversion and quantization](/docs/showcase/ai/machine-learning/model-conversion) | Create hardware-specific variants and validate compatibility and quality. |
| [Computer vision training](/docs/showcase/ai/machine-learning/computer-vision) | Expose collection, labels, augmentation, training, and packaging as observable stages. |
| [Anomaly detection](/docs/showcase/ai/machine-learning/anomaly-detection) | Train a detector and make threshold selection an explicit workflow decision. |
| [Model ensemble](/docs/showcase/ai/machine-learning/model-ensemble) | Run independent predictors and combine them through a versioned aggregation rule. |
| [Model distillation](/docs/showcase/ai/machine-learning/model-distillation) | Generate teacher targets and train a smaller student with measured quality and latency. |
| [Inference benchmark](/docs/showcase/ai/machine-learning/inference-benchmark) | Compare one frozen model and input set across CPU, GPU, and edge targets. |
| [Infrastructure selection for training](/docs/showcase/ai/machine-learning/infrastructure-selection) | Compare plans for local GPU, HPC, and cloud before executing the selected candidate. |

# Document Intelligence

This example processes synthetic invoices and a purchase order through explicit ingestion, classification, extraction, reconciliation, and reporting activities. It verifies totals and duplicate invoice identifiers rather than stopping after text extraction.

## Run locally

```bash
git clone https://github.com/UFFeScience/akoflow-examples.git
cd akoflow-examples/document-ai/document-intelligence
./run.sh
```

The fixture is intentionally small and private-data-free. Replace `data/documents` with a larger local corpus while preserving the same artifact contract.

# Edge to cloud simulation

<WorkflowDiagram kind="edge-cloud" />

This deterministic example runs `prepare → analyze → summarize`. The middle activity benefits from the faster cloud resource, but moving it introduces two network transfers and a non-zero cloud cost. It is a compact example of the trade-off evaluated by PRISM Time, PRISM Cost, and HEFT.

## Expected evidence

The run contains three settled activities, two cross-resource data transfers, predicted and observed makespan/cost, the selected assignments, and the SimGrid trace. The execution bundle is also preserved under `storage/simgrid/` for reproduction.

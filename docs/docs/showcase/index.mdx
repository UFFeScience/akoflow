# Workflow showcase

Browse every example below by section: Simple examples, Machine Learning, Generative AI, Agentic workflows, and Scientific AI. Select a graph to open its page. The runnable bundles are maintained in the dedicated [`UFFeScience/akoflow-examples`](https://github.com/UFFeScience/akoflow-examples) repository.

<WorkflowCatalog />

## How to use a showcase

1. Clone `UFFeScience/akoflow-examples`, choose a runnable example, and open its directory. Product releases and examples are versioned independently; use the revision stated by the example when one is required.
2. Complete the scenario's prerequisites and [API connection setup](/docs/tutorials/api-access) when using an existing server. The SLURM fixture starts its own server and sets its API URL in the procedure.
3. Submit the files in the stated order and wait for the run to finish.
4. Check the result listed on that scenario's page.

The files define the submitted model. If Desktop is connected to the same server, use it to inspect the saved records and result.

```bash
git clone https://github.com/UFFeScience/akoflow-examples.git
```

# Showcases

Explore 22 executable workflows organized by scientific objective. Each page explains the workflow DAG, activity responsibilities, inputs, outputs, provenance, and execution considerations without embedding implementation code in the documentation.

The complete Dockerfiles, Python programs, generators, input fixtures, runners, and validators are maintained separately in [`UFFeScience/akoflow-examples`](https://github.com/UFFeScience/akoflow-examples). A single source-bundle link on each page connects the explanation to its versioned implementation.

## Choose a category

- **Machine Learning** — training, tuning, inference, evaluation, conversion, vision, ensembles, and infrastructure selection.
- **Generative AI** — retrieval, synthetic data, audio transcription, and document extraction.
- **Agentic workflows** — bounded agents, supervised tool use, and multi-agent review.
- **Scientific AI** — AI-assisted analysis, surrogate models, and experiment feedback loops.

## Validation model

Every source bundle is exercised by the centralized examples CI. The regression fixture verifies its declared local inputs and outputs; provider-specific execution on HPC, Kubernetes, or cloud infrastructure still depends on the environment and permissions described by the corresponding infrastructure guide.

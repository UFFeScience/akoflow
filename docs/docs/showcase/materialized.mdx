# Materialized showcases

The 22 showcase directories in [`UFFeScience/akoflow-examples`](https://github.com/UFFeScience/akoflow-examples) are deterministic Docker-backed workflow fixtures. Each one contains its AkôFlow YAML definition, local environment/scope/topology, input data, expected-output contract, OCI Dockerfile, runner, validator, and screenshot automation. This documentation links directly to those independently versioned source bundles.

## Run and validate

From an individual directory, run `./run.sh`. It builds the local image, executes it, writes `outputs/`, takes `workflow.png`, `execution.png`, and `outputs.png`, then checks the expected manifest. CI publishes the same image to GHCR under `ghcr.io/uffescience/akoflow-showcase-<name>` with `latest`, `v1`, and `v1.0.0`.

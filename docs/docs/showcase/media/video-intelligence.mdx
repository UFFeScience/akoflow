# Video Intelligence

The workflow creates a known three-scene video, inspects its streams, extracts scene thumbnails, measures audio, and assembles a searchable timeline. The known input makes scene and duration assertions deterministic while still exercising real FFmpeg processing in the OCI image.

## Run locally

```bash
git clone https://github.com/UFFeScience/akoflow-examples.git
cd akoflow-examples/media/video-intelligence
./run.sh
```

Minimal hosts use a deterministic portable fixture. The container installs FFmpeg and FFprobe and performs the complete media path.

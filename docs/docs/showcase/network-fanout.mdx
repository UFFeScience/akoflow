# 30 GB network fan-out

<WorkflowDiagram kind="fanout" />

`t1` produces three 10 GB dependencies. `t2`, `t3`, and `t4` run concurrently on the three cores of M2 and each sends 10 GB to `t5` on M3. The example makes endpoint contention visible: concurrent flows share the link instead of each receiving its full nominal bandwidth.

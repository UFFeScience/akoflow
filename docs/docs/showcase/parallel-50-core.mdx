# 100 activities on 50 cores

<WorkflowDiagram kind="parallel" />

This workload separates *machine capacity* from *activity count*. One hundred independent activities are eligible for a simulated machine with 50 cores, so two waves are expected when every activity requests one core. The example is useful for detecting plans that accidentally treat a machine as one slot or display only the cores that received work.

## Checks after execution

- Exactly 100 activities settle.
- No activity consumes more cores than requested by the workflow.
- The Gantt can show all lanes without constructing thousands of off-screen DOM nodes.
- Planned and observed evidence retain execution, queue, and transfer components separately.

# Blender Render Farm

This example creates a procedural Blender scene, divides frames into even and odd shards, renders both activities independently, and composes the complete sequence. The fan-out makes resource placement and parallel makespan visible in an AkôFlow plan.

## Run locally

```bash
git clone https://github.com/UFFeScience/akoflow-examples.git
cd akoflow-examples/rendering/blender-render-farm
./run.sh
```

The OCI image contains Blender and FFmpeg. A deterministic CPU software-render fixture keeps validation possible on minimal CI machines; set `AKOFLOW_REQUIRE_BLENDER=1` when Blender execution is mandatory.

# Montage 050 — Astronomical Image Mosaicking

Combine twelve astronomical FITS observations into calibrated three-band mosaics. The 58-activity workflow projects the input images, fits background differences, corrects each band and assembles FITS mosaics and a color preview. Execution location is selected through the profiles below; it is not a different scientific workflow.

## Execution profiles

| Profile | Configuration | Validation status |
| --- | --- | --- |
| Local Docker | Two CPU slots and the pinned amd64 image | **Executed: 58/58 activities completed**, three FITS mosaics and four PNG previews validated |
| GCP + local processing | Four GCP workers for projection, remaining stages on the local runtime | **Reference configuration; not executed in this validation** |

The published import URI and measured results below use the local Docker profile. See the [GCP deployment profile](/docs/showcase/montage-cloud-local) for the optional cloud setup, prerequisites and original configuration. There is **one Montage Hub publication and one validated reference execution**, not separate local and GCP results.

## Inputs and outputs

The immutable upstream image contains 87 MiB of source FITS data, region headers, tables, and native Montage executables. The local command produces three 1800 × 1800 FITS mosaics, three monochrome PNG previews, a color preview, an output manifest, and one execution record per activity.

This is the full scientific workload. It can take substantially longer than the small CPU examples, especially under amd64 emulation on Apple Silicon. Preparation and CI validate the image, twelve source observations, all 58 native commands, and 138 file handoffs. That preparation check does not execute the full workload or certify final mosaic outputs.

Run `./validate.sh` after the standalone workflow finishes. It checks that all 58 activity records completed, parses FITS image dimensions, and decodes PNG headers. The historical duration profiles inherited from the source workflow were measured on another CPU and are not local timing measurements.

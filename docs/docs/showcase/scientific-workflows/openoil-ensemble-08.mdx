# OpenOil ensemble — 8 members

Track the drift and weathering of an oil spill offshore of Maricá/Niterói, Brazil. Each member executes the real OpenDrift OpenOil model in its own Docker activity. The 8 members fan out independently and join for ensemble aggregation; map, summary and animation rendering then run independently before a final scientific validation.

## Scenario and scientific limits

The executed scenario uses **1,000 particles per member**, **172 simulated hours**, and a **16-hour release at 250 m³/h (4,000 m³ total)**. Parameter sampling uses seed 42; member `i` uses OpenOil seed `42 + i`. The first eight members are shared across all three ensemble sizes, and the first sixteen are shared by the 16- and 32-member variants.

Wind and current are synthetic, spatially and temporally constant within each member. The coastline mask and oil-weathering model are real, but these outputs are **not an operational forecast or response recommendation**. These are measured computations, not simulated workflow durations. The supplied notebook introduction describes different scenario values; this implementation follows its executable configuration.

## Docker execution

The image is published for **linux/amd64 and linux/arm64**. Each run uses two CPU execution slots, so only two ensemble members run at once. The three full experiments were scheduled serially on the homeserver: **8 → 16 → 32**, with terminal status and scientific output validation required before the next run starts.

Use the source bundle linked in the Hub widget for the Dockerfile, locked Python dependencies, workflow YAML, local environment, scope, topology and validator. Pull the image before an offline execution; no hosted API, cloud account or runtime internet connection is required.

## Data and validation

Download all member NetCDF trajectories, the gridded probability NetCDF, mass-balance and coast-arrival CSVs, per-stage measured profiles, PNGs, GIF, checksums and native AkôFlow execution capture from the Hub. Validation checks time axes, particle counts, finite nonnegative oil mass, post-release mass conservation within 1%, probability bounds/counts, decoded PNGs and a multi-frame GIF.

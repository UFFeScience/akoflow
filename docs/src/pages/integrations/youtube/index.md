# AkôFlow Video Publisher

AkôFlow Video Publisher is a command-line tool used by the AkôFlow video operator to upload tutorials to the UFFeScience Research Group YouTube channel from a private homeserver.

The operator authorizes the channel through Google's OAuth consent screen. The tool uses the official YouTube Data API to upload an approved video, add its English captions, and place it in the AkôFlow Guide playlist. New videos and playlists are unlisted by default. Publication requires an explicit instruction from the operator.

This connection is for the project's video publishing workflow. AkôFlow Desktop users do not need to connect a Google account to create or run scientific workflows.

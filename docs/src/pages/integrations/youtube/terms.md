# Video Publisher Terms of Use

Effective date: November 8, 2026.

These terms apply to Akoflow Video - homeserver, the operator-managed AkôFlow Video Publisher used to publish AkôFlow tutorials from a private homeserver.

## Authorized use

Use the publisher only with a YouTube channel you are authorized to manage and content you have the right to upload. The configured publishing workflow checks the UFFeScience Research Group channel before making changes. Access to this tool does not give another person permission to manage that channel.

Each publication must be requested by an authorized operator. Review the selected video, title, description, captions, and visibility before submitting it. New uploads and playlists are unlisted by default. An unlisted video can be viewed and shared by anyone who has its link.

By using the YouTube publishing integration, users agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Use of Google APIs must also comply with the applicable [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service) and [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy).

The integration is subject to Google's authorization, API quotas, availability, and processing requirements. It does not guarantee immediate processing or uninterrupted access.

## Credentials and control

Keep client credentials and OAuth tokens private. Do not place them in a browser bundle, public media directory, video, or source repository. Operators can revoke access through [Google Account connections](https://myaccount.google.com/connections) and manage published content through [YouTube Studio](https://studio.youtube.com/).

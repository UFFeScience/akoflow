# AkôFlow examples

The four showcase families provide 22 executable, Docker-backed workflow fixtures. Every showcase directory contains its workflow graph, environment/scope/topology inputs, deterministic input data, expected artifact contract, Dockerfile, local runner, validator, and screenshot automation.

Run a showcase from its directory with `./run.sh`. The [materialized showcase catalog](../docs/docs/showcase/materialized.mdx) lists every fixture and its published GHCR image name.

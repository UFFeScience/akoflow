# PRISM Time: native HEFT reference

Algorithm version 4 evaluates the actual native insertion HEFT output with
the same complete evaluator used for PRISM search survivors. The reference
is appended after beam pruning and participates in the final time ranking.
It is not a HEFT-like placement generated by PRISM's placement operators.
The HEFT input is captured before PRISM's workspace-dependency projection,
so the reference matches an independent HEFT run on the original snapshot.

When HEFT wins, `candidateOrigin=heft-baseline` preserves that provenance;
otherwise it is `prism-search`. The native HEFT prediction is replaced by
the common evaluation, while its activity/resource/core/slot/order/priority
assignments remain unchanged. Plans record `heftBaselineIncluded` and, when
included, `heftBaselineEvaluatedMakespanSeconds`. Unexpected evaluator errors
are surfaced rather than silently dropping the reference.

The reference must meet PRISM placement eligibility (including measured-profile
requirements) and its storage budget. Ineligible references are skipped with
`heftBaselineUnavailable`; deadline and monetary constraints still apply in
the existing final candidate filter. Thus the first time candidate is no worse
in common-model score than an included eligible HEFT reference, under the same
final feasibility rules. PRISM Cost retains its previous behavior/version.

This is not a universal guarantee about native SimGrid or real makespan.
The PRISM evaluator and native engine have small timing differences. Validate
the selected candidate and reference independently when comparing simulations;
real performance also depends on calibration and runtime conditions. The
Figure 8 diagnostic runs do this native verification for all six plans.

Regression coverage includes a narrow-beam case that loses the better insertion
HEFT placement, preservation of executable assignment fields and provenance,
placement eligibility and cancellation. Production defaults, live inventory
and existing executions are not rewritten when this version is compiled.

## What’s new

This release adds installation health checks, support bundles, guided instance backup and restore, and recoverable drafts. It also brings pinned execution schedules, shareable execution views, and Hub publishing and import improvements.

The evidence below comes from development tests. Production verification is pending for telemetry ([#200](https://github.com/UFFeScience/akoflow/issues/200)). The two-machine acceptance run is pending for Hub contributions ([#308](https://github.com/UFFeScience/akoflow/issues/308)).

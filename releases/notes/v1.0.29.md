## What’s fixed

- Installed Desktop can now send telemetry after opt-in without manually configuring an environment variable. Each installation creates its own ingestion credential. The local daemon receives the same credential through the native consent channel.
- Existing preferences carry forward. Installations with sharing disabled do not register or send any events.

## What’s new

- **Hub execution history.** Publish a run to a pinned workflow version, approve collaborator contributions, and compare authors, observed duration, hardware, and resource allocation. Users can also share an execution from their own profile. Desktop import lets the user choose a past machine and execution as the reference for timing estimates. [Issue and validation evidence](https://github.com/UFFeScience/akoflow/issues/308#issuecomment-6992740703)
- **Slurm preparation and provenance.** Prepare pinned SIF images before submitting jobs, show preparation and runtime wait reasons inside activity cards, and link each attempt to the executable that actually ran. [SIF preparation](https://github.com/UFFeScience/akoflow/issues/322) · [Executable provenance](https://github.com/UFFeScience/akoflow/issues/323) · [Activity wait reasons](https://github.com/UFFeScience/akoflow/issues/326)
- **Execution sharing review.** Review exactly what will be shared, confirm the selected execution, and copy its Hub link. [Confirmation](https://github.com/UFFeScience/akoflow/issues/324) · [Public sharing review](https://github.com/UFFeScience/akoflow/issues/325)
- **Run diagnosis.** Jump from the first recorded failure to its logs and recovery, preserve the activity and attempt across views, and search or filter the live log stream by source. [Failure diagnosis](https://github.com/UFFeScience/akoflow/issues/327) · [Attempt navigation](https://github.com/UFFeScience/akoflow/issues/328) · [Live logs](https://github.com/UFFeScience/akoflow/issues/329)
- **Planning and navigation.** Compare two candidates side by side while preserving the selected plan. Open recent workflows and runs, jump to the latest failed run, and copy links from global search using the keyboard. [Plan comparison](https://github.com/UFFeScience/akoflow/issues/330) · [Global search](https://github.com/UFFeScience/akoflow/issues/331)
- **Isolated activity tests.** Review the exact retained files from an earlier attempt and run the selected activity in a separate run. The daemon reports missing files before submission and verifies checksums during transfer. [Issue and validation evidence](https://github.com/UFFeScience/akoflow/issues/332#issuecomment-6990897916)

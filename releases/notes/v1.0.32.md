## What’s new

- **Publish imported runs from Desktop.** Share a complete execution on the Hub version it came from, or publish an edited workflow as a fork. The daemon verifies the executed definition before attaching a result to its source version. [Slurm validation](https://github.com/UFFeScience/akoflow/issues/340#issuecomment-7008777126)
- **Choose an execution as a planning reference.** Select a past author and run to use its observed timings. Workflows without recorded timings continue to use their default estimates.
- **Execution graph layout.** Activity nodes and their edges stay aligned in the execution overview.
- **Examples catalog.** The six-stage TCGA-BRCA microRNA network workflow is now on the examples repository’s default branch. [TRP example](https://github.com/UFFeScience/akoflow-examples/tree/main/scientific-workflows/trp)

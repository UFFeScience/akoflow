## Desktop, daemon and Hub

- **Publish from one dialog.** Review the destination and exact workflow version before sharing an execution. All capture sections are selected by default, with a warning before review and per-section controls. The same dialog can share an authorized summary on your Hub profile when the original workflow is restricted.
- **Import and plan.** Desktop uses comparable execution history automatically for the pinned Hub version. Workflows without usable history continue to use the default estimate.
- **Manage environment connections.** Delete an unused connection from the environment map. The daemon rejects deletion when a runtime, active execution or other dependency still uses it.
- **Inspect Slurm attempts.** The Hub distinguishes the node and allocation for each attempt, including retries that change nodes. Captured plans with no dependencies render in the viewer.
- **Identify imported artifacts.** The catalog uses workflow and activity names, disambiguates collisions and preserves immutable image identities. Reviewing and sharing the same capture again returns the existing result.
- **Keep the execution overview connected.** The links between activities, execution environments, plans and outputs render while the graph measures its cards.
- **Recover from denied or expired Hub authorization.** The Desktop clears the waiting state and keeps the explanation visible when a sign-in request ends.

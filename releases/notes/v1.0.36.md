## Update AkôFlow components from Desktop

Install Desktop 1.0.36 once to enable component updates. Future compatible updates appear under **Settings → Updates** and download only the frontend, daemon, or BuildKit components that changed. Updates to Electron or native integrations still use the Desktop installer.

When an update is available, Desktop offers **Update now** or **Not now** on startup. The startup screen shows download progress after you accept.

Desktop verifies the signed manifest and the checksum of each changed artifact before applying it. If an execution is active, Desktop asks you to finish it before replacing the daemon. Coordinated updates switch the frontend after the daemon is healthy. The runtime uses the existing data volumes for history and settings.
